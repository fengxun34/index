# 醫師問診流程訪談表

> 用途：訪談診所醫師，把醫師實際的問診流程與照護原則整理出來，
> 再填進系統的「⚙️ 診所設定」頁（`http://127.0.0.1:8000/api/admin/clinic`）。
> 每個部位約 10～15 分鐘，建議錄音（先取得醫師同意）方便事後整理。

## 一、問診題目（每個部位各填一份）
部位：□頸椎 □腰椎 □肩關節 □肘腕 □髖關節 □膝關節 □足踝 □外傷 □兒童 □腫瘤 □高壓氧 □其他：____

1. 病人說這個部位不舒服時，您**第一個**會問什麼？為什麼？
2. 接下來會依序問哪些問題？（請照順序列出 3～5 題）

   | 順序 | 題目（用病人聽得懂的說法） | 常見回答（可做成快捷選項） |
   |---|---|---|
   | 1 | | |
   | 2 | | |
   | 3 | | |
   | 4 | | |
   | 5 | | |

3. 哪些回答會讓您覺得**需要馬上處理或轉急診**？（警訊）
4. 哪些回答會讓您覺得**應該轉診到大醫院**？
5. 病人常用什麼「口語說法」描述這個問題？（例如：膝蓋卡卡、閃到腰、手麻麻的）

## 二、診所知識（可填多筆）
| 標題 | 適用部位 | 病人常見說法／關鍵字 | 醫師的處理原則或建議 | 警訊 |
|---|---|---|---|---|
| 例：退化性膝關節炎處理原則 | 膝關節 | 膝蓋痛、上下樓梯痛、蹲下痛 | 先照 X 光評估；輕中度以肌力訓練與復健為主，可考慮玻尿酸注射 | 突然紅腫熱痛合併發燒請立即就醫 |
| | | | | |
| | | | | |

可以涵蓋：診所提供的療程（震波、PRP、復健）、常見診斷的處理原則、術後／受傷後照護、需要轉診的情況。

## 三、看診前摘要
1. 進診間前，您最希望先知道病人的哪些資訊？
2. 目前「今日看診清單」顯示的內容（主訴、問答、上次看診、知識庫提醒），有沒有多餘或缺少的？
3. 有沒有需要特別標示的情況？（例如：第一次來、很久沒回診、曾經轉診）
