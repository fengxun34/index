# 醫語搞定-AI智慧語音掛號助理：安裝與使用

## 1. 放置檔案
解壓縮後整個資料夾就是完整專案（資料夾名稱 `0930` 可自訂）。
**這個包裡沒有 `.env`（金鑰不能打包）**：把你舊 `0930` 裡的 `.env` 複製進來；沒有舊檔就複製 `.env.example` 改名為 `.env`，填入 Supabase 的 URL 與 key。

## 2. 輸入金鑰（在 `.env`）
    OPENAI_API_KEY=sk-你的金鑰
    OPENAI_MODEL=gpt-4o-mini
沒有填金鑰，系統自動使用規則版（問診題固定順序），仍可正常使用。`.env` 不要上傳 GitHub、不要貼給別人。

## 3. 安裝套件（只做一次）
    cd /d C:\Users\你的帳號\Desktop\0930
    python -m venv venv
    venv\Scripts\activate
    pip install -r requirements_true_rag.txt
    pip install tzdata

## 4. 啟動
    venv\Scripts\activate
    python check_setup.py          （檢查環境與金鑰，有 ❌ 就照 👉 處理）
    uvicorn app:app --reload       （視窗不要關）
用 Chrome 開 `index.html`（更新後按 Ctrl+F5）。LINE 通知另開視窗：`python line_worker.py`。

## 5. 資料庫
- 一般使用不用改資料庫。
- 要用 LINE 通知：Supabase → SQL Editor 貼上 `sql/006_line_notifications.sql` 按 Run。
- 自訂題目／診所知識庫需要 `sql/005_clinic_customization.sql`（之前跑過就不用再跑）。

## 6. 問診流程（2～4 題）
1. 病患說「我膝蓋痛」。
2. **兩項警訊篩檢題固定先問**（規則決定，GPT 不能略過）。回答命中警訊 → 立即中止並提醒就醫／急診。
3. 之後由 GPT 依回答與 RAG 檢索到的知識片段，從診所題庫「適用且尚未問過」的題目中挑下一題；
   問完警訊題與至少 1 題後，資訊足夠 GPT 可提前結束；**最多 4 題**。沒有金鑰就照題庫順序問。
4. 問診結束：規則算出問題類型 → RAG 檢索 → GPT 在檢索到的類型範圍內判斷；與規則不同時以 GPT 為準重新推薦醫師
   （轉診類別如腫塊、高壓氧維持規則結果）。
5. 自動排最快時段，病患說「確定」才掛號。已登入且資料完整者不用重填資料。
- 範圍：12 種部位／流程共 130 個題庫項目，條件追問會依回答略過不適用的題目。
- 所有醫療內容為 AI 整理的示範草稿，待診所醫師確認（見「醫師確認清單.md」「各部位測試與醫師確認.md」）。
