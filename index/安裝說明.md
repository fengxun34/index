# 安裝說明（完整版）

## 1. 放置檔案
這是完整專案：解壓縮後整個資料夾直接使用
**這個包裡沒有 `.env`（金鑰不能打包）**：把你舊 `0930` 裡的 `.env` 複製進來（內有 Supabase 設定）；沒有舊檔的話，複製 `.env.example` 改名為 `.env` 再填入 Supabase 的 URL 與 key。
舊的 `venv` 也可以複製進來沿用，否則第一次要執行：`python -m venv venv`。

## 2. 輸入金鑰：在 `0930` 資料夾的 `.env` 檔
用記事本開啟 `.env`，在最後加上（等號後面貼你的金鑰，不要加引號、不要有空格）：

    OPENAI_API_KEY=sk-你的金鑰
    OPENAI_MODEL=gpt-4o-mini

沒有填金鑰，聊天助理會自動使用原本的規則版，系統照常能用。
`.env` 絕對不要上傳 GitHub、不要貼給別人。

## 3. 安裝新套件（只要做一次）
    cd /d C:\Users\奉聖勳\Desktop\0930
    venv\Scripts\activate
    pip install -r requirements_true_rag.txt
    pip install tzdata

## 4. 資料庫要不要改？
- **使用 OpenAI 聊天助理、重複掛號／過去時段防呆：不用改資料庫。**
- **要用 LINE 通知才需要**：Supabase → SQL Editor → New query，貼上 `sql/006_line_notifications.sql` 全文按 Run（只新增 3 張表和函式，不會刪資料）。不用 LINE 就不用跑。
- 原本的 schema、004、005 如果之前跑過就不用再跑。

## 5. 啟動
    cd /d C:\Users\奉聖勳\Desktop\0930
    venv\Scripts\activate
    python check_setup.py          （檢查環境，第 9 項會檢查 OpenAI 金鑰）
    uvicorn app:app --reload       （視窗不要關）

然後用 Chrome 開 `index.html`。
LINE 通知另開一個視窗執行：`python line_worker.py`（要先照 README_LINE.md 設定 LINE）。

## 7. 本次更新內容
- 聊天式掛號助理可用 GPT（agent_llm.py）：掛號只能掛診所醫師與查到的時段、要病患明確說「確定」才執行；回答只依診所知識庫；身分證／生日／手機不送給 OpenAI。
- 後端擋過去時段、同人同時段重複掛號（含改期）。
- LINE 綁定與掛號／前一天提醒通知。
- check_setup.py 新增 OpenAI 檢查。

- 主畫面問診：GPT 做判斷，但由 RAG 限制範圍（rag_generate.py）。候選類型只來自檢索到的知識片段，GPT 必須引用屬於所選類型的片段；理由不得出現藥物劑量／診斷用語，數字須出自片段。任何一項不過，就維持原本的規則判斷。急症仍由規則優先處理。
- 問診每個部位增加追問（發生方式、加重動作、腫脹／夜間痛、各部位專屬問題），共 5～7 題；若診所設定頁曾自訂某部位題目，該部位仍用自訂題目。
- 已登入且帳號資料完整時，掛號畫面不再要求填基本資料，只顯示確認內容（可按「資料有誤？修改」）。
- GPT 聊天助理會先問 3～5 個關鍵問題再推薦時段。
- 開啟網頁預設進入 AI 聊天掛號助理（聊天畫面底下「回主畫面」可改用按鈕式流程）。
- 主畫面問診：每答完一題，GPT 依回答從診所題庫挑下一題（只能挑題庫內的題目），資訊足夠且已問滿 3 題可提前結束（triage_questions.py）；沒有金鑰就照題庫順序。
- 已移除「用藥提醒」，保留復健提醒。
- 問診限制為 2～4 題（GPT 判斷資訊足夠時 2～3 題就結束，最多 4 題；沒有金鑰則固定問題庫前 4 題）。
- 問診結束後，若 GPT 的判斷（限於 RAG 檢索到的類型）與規則不同，以 GPT 判斷重新推薦醫師與時段；轉診類別（疑似腫瘤、高壓氧）維持規則結果。
